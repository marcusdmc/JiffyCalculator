# Jiffy Calculator

A browser-based exposure guide inspired by the printed New Jiffy Calculator. Open `index.html` in a modern browser; no build or installation is required.

Choose one of the 26 scenes, the film ISO, and an aperture to see the corresponding shutter time. The table shows the original slide's equivalent half-stop combinations. Values outside the printed shutter scale are marked rather than extrapolated.

These are estimates, not meter readings. Bracket exposures when practical and consult your film's datasheet for reciprocity failure on long exposures. The original calculator credits S. P. Martin, Fred Parker, and M. Zomborszki.
